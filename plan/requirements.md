# 用户需求记录

## 2026-06-09 - 初始需求

### 用户原话

做的是有一个有GUI的是在状态栏能够看到的，能够设置的，你可以在里面输入校园网账号和密码的，最终做出来要变成就是要比较方便的变成一个编译成二进制文件，不同电脑可以一起使用的，然后要求它小巧好用的那种，占用资源也得少

### 需求分析上下文

- 校园网是 Dr.COM 认证系统，服务器 210.44.114.32，认证端口 801
- 校园网特别不稳定，容易突然退出登录，电脑就没网了
- 用户常用远程工具，电脑需要一直在线
- 需要自动检测掉线并重新登录，无需人工干预

### 提取的需求清单

1. **系统托盘常驻** - 程序运行后在 Windows 状态栏（系统托盘）显示图标，不占任务栏
2. **状态图标显示** - 用不同颜色图标表示状态：绿色=在线，红色=离线，黄色=重连中
3. **GUI 设置窗口** - 右键托盘图标可打开设置窗口，输入账号、密码、选择运营商
4. **网络状态检测** - 定时检测网络连接状态（ping 网关 + HTTP 探测认证页面）
5. **自动登录** - 检测到掉线后，自动 POST 请求 Dr.COM 认证接口重新登录
6. **重试机制** - 登录失败自动重试，递增间隔，连续失败多次后等待更长时间
7. **开机自启** - 支开机自动启动，托盘菜单可切换开关
8. **日志记录** - 记录掉线、重连、错误等事件
9. **编译成 exe** - 打包成单个二进制文件，不同电脑直接运行，无需安装依赖
10. **小巧低占用** - 体积 < 10MB，内存占用 < 20MB

### 技术约束

- 语言：Go
- GUI 框架：walk（Windows 原生 Win32 风格，体积最小）
- 认证接口：
  - 登录：POST http://210.44.114.32:801/eportal/?c=ACSetting&a=Login&url=drappall
  - 字段：DDDDD=账号@运营商后缀，upass=密码
  - 运营商后缀：@dx(电信)、@lt(联通)、空(校园/移动)
  - 注销：http://210.44.114.32:801/eportal/?c=ACSetting&a=Logout&ver=1.0

## 2026-06-09 - 用户确认

### 确认结果

1. **检测间隔** - 用户可自定义，默认 30 秒
2. **通知方式** - 两者都要：图标变色 + 托盘气泡通知
3. **密码存储** - 明文存储在配置文件
4. **运营商后缀** - 不需要，用户确认移动校园网用纯账号登录即可

### 更新后的认证参数

- 账号字段：`DDDDD=2023405021`（无后缀）
- 密码字段：`upass=密码明文`

## 2026-06-09 - 完整需求确认（v0.1.0）

### 技术选型

- 语言：Go
- GUI 框架：walk（Windows 原生 Win32 控件）
- 界面风格：深色主题
- 打包方式：NSIS 安装程序
- 版本号：v0.1.0

### 功能需求

#### 1. 系统托盘
- 程序启动后常驻系统托盘
- 三种状态图标：绿色（在线）、红色（离线）、黄色（重连中）
- 鼠标悬停显示当前状态 tooltip
- 右键菜单：设置、状态窗口、手动重连、开机自启（勾选）、退出

#### 2. 设置窗口（完整版）
- 账号输入框
- 密码输入框（密文显示）
- 运营商下拉选择（校园用户/校园电信@dx/校园联通@lt/校园其他）
- 默认选"校园用户"（无后缀）
- 认证服务器地址输入框（默认 210.44.114.32）
- 检测间隔输入框（默认 30 秒）
- 开机自启勾选框
- 弹窗通知勾选框
- 保存按钮
- 测试登录按钮
- 多账号管理：下拉切换已保存的账号，新增/删除账号

#### 3. 状态窗口（详细版，纯文字）
- 当前状态（在线/离线/重连中）
- 当前账号
- 当前 IP 地址
- 在线时长
- 已用流量
- 最近 10 条日志记录
- 手动重连按钮

#### 4. 网络检测
- 主检测方式：Ping 认证网关（210.44.114.32）
- Ping 不通 = 掉线
- Ping 通 = 在线
- 检测超时：单次不超过 10 秒
- 检测间隔：用户可配置，默认 30 秒

#### 5. 自动登录（智能判断）
- 检测到掉线后，先尝试直接 POST 登录
- 登录成功 → 更新状态
- 登录失败 → 发送注销请求 → 等待 1 秒 → 再次登录
- 重试机制：最多 5 次，间隔递增（3s → 5s → 10s）
- 连续失败 5 次 → 等待 60 秒后继续检测

#### 6. 密码存储（简单加密）
- 配置文件使用简单异或加密
- 防止肉眼直接看到明文
- 配置文件位置：%APPDATA%/campus-keepalive/config.json

#### 7. 日志功能
- 文件日志：%APPDATA%/campus-keepalive/keepalive.log
- 带时间戳
- 日志级别：INFO、WARN、ERROR
- 文件超过 5MB 自动轮转
- 托盘 tooltip 显示最近状态

#### 8. 全局快捷键
- Ctrl+Alt+L：手动触发重新登录
- 简单实现，不提供自定义快捷键

#### 9. 开机自启
- 写入注册表实现
- 托盘菜单可切换开关

#### 10. 安装程序
- NSIS 打包
- 安装到 Program Files
- 创建开始菜单快捷方式
- 支持卸载

### 认证接口详情

```
登录：
POST http://{server}:801/eportal/?c=ACSetting&a=Login&url=drappall
Content-Type: application/x-www-form-urlencoded
Body: DDDDD={账号}{运营商后缀}&upass={密码}

注销：
GET http://{server}:801/eportal/?c=ACSetting&a=Logout&ver=1.0

运营商后缀：
- 校园用户：（空）
- 校园电信：@dx
- 校园联通：@lt
- 校园其他：（空）
```
